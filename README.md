# 鲜管家 · 智能冰箱管家 APP（设计原型 v0.1.0）

> 一人公司方向验证项目 · 设计原型阶段（非可运行产品，用于演示与收集反馈）

## 这是什么
一个帮你管冰箱里有什么、并自动安排一日三餐的手机 APP 原型：
- **入库**：扫条形码 / 手动选，记录菜名、保质期、价格
- **库存**：看清冰箱里有什么、还剩几天坏、花了多少钱
- **配餐**：按库存 + 营养需求 + 预算，生成一天三餐，并算出每餐花费
- **花费**：每日 / 每周花费，营养达标进度，对比外卖省了多少

## 怎么看原型
直接用浏览器打开 `index.html` 即可（手机模式体验最佳）：
- 底部 4 个 tab：库存 / 配餐 / 花费 / 我的
- 中间「+」按钮：添加食材（可演示实时入库）

## 当前范围（MVP）
只做上面四件的可演示原型，数据均为示例。
**暂不做**：摄像头识别生鲜（先做手动+条形码）、冰箱贴硬件、付费/分佣。

## 设计系统
清新食材风：鲜绿 `#2E7D5B` + 奶白底 `#F4F7F2` + 暖橙强调 `#F2A541`。
