## 为什么做这个

冰箱里的菜放坏了、不知道今晚吃啥、每月买菜花多少钱心里没数——这是每个家庭都有的痛点。市面上要么把功能锁死在万元智能冰箱里（卡萨帝 / 海尔），要么只做菜谱社区、不管你冰箱里有什么（下厨房）。

**鲜管家的位置**：不挑冰箱、不锁硬件，把「库存 → 自动配餐 → 营养 → 花费」做成一条完整闭环，而且**代码全部开源**——你管的是冰箱和花钱，这种隐私数据，开源才信得过。

## 核心闭环

```
扫条形码 / 手动入库  →  库存总览（剩几天坏、花了多少）
        ↓
   按库存 + 营养需求 + 预算  →  生成一日三餐 + 每餐花费
        ↓
   防浪费提醒  +  营养达标进度  +  对比外卖省了多少
```

## 差异化（vs 现有产品）

| | 鲜管家 | 卡萨帝 / 海尔智能冰箱 | 下厨房 / 薄荷 |
|---|--------|------------------|------------|
| 绑定硬件 | ❌ 任何冰箱可用 | ✅ 锁死本品牌（8000+ 元） | — |
| 库存→配餐闭环 | ✅ 全闭环 | 部分 | ❌ 不做闭环 |
| 开源可信 | ✅ MIT | ❌ | ❌ |
| 价格 / 营养计算 | ✅ | 弱 | 部分 |

## 功能一览（原型已含）

- **库存**：看清冰箱里有什么、还剩几天坏、一共花了多少钱
- **入库**：扫条形码 / 手动选，记录菜名、保质期、价格
- **配餐**：按库存 + 营养需求 + 预算，生成一日三餐，显示每餐花费
- **花费**：每日 / 每周花费、营养达标进度、对比外卖省了多少
- **我的**：设置家庭人数、营养目标、预算
